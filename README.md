# Laetitia ♥ Raph

Petit site rien qu'à nous, en rose clair et rose foncé.

- **Nous** : compteur en direct depuis le 30 mars 2021 et nos photos
- **New York** : idées d'activités à cocher (♡ Envie / ✓ Fait), date de départ avec compte à rebours, un programme sur 5 jours et nos notes
- **Je t'aime** : « je t'aime » en 32 langues (touchez une carte pour voir la langue), avec nos photos

Il suffit d'ouvrir `index.html` dans un navigateur. Pour ajouter des photos, placez-les dans `photos/` et ajoutez-les à la liste `PHOTOS` dans `script.js`.

Pour le mettre en ligne gratuitement : GitHub → Settings → Pages → Branch `main` → `/ (root)`.
